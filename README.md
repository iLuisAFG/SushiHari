# Sushi Hari 🍣

Sitio web oficial y responsivo de **Sushi Hari**, restaurante de sushi artesanal ubicado en la Alcaldía Gustavo A. Madero, Ciudad de México. Diseñado con una interfaz moderna, elegante y optimizada para la conversión.

---

## 🚀 Tecnologías Utilizadas

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animaciones:** [Framer Motion](https://www.framer.com/motion/)
- **Iconografía:** [Lucide React](https://lucide.dev/)
- **Diseño UI/UX:** Sistema de diseño basado en la skill *UI/UX Pro Max*

---

## ✨ Características Principales

- **Hero Interactivo:** Llamado a la acción rápido con accesos directos al menú digital y pedidos por WhatsApp.
- **Sección de Especialidades:** Catálogo interactivo con filtros por categoría (*Platillos Insignia*, *Makis de Autor*, *Arroces & Bowls*, *Paquetes & Combos*), precios reales y botón directo para ordenar el platillo seleccionado por WhatsApp sin emojis.
- **Menú PDF Oficial:** Visualizador interactivo integrado y botón de descarga directa de la carta completa (`Menu.pdf`).
- **Horarios y Ubicación:** Integración con Google Maps, horarios de lunes a domingo (12:00 p.m. a 8:00 p.m.) y dirección completa.
- **Navegación Fluida:** Barra de navegación *glassmorphism* fija con menú responsivo para dispositivos móviles.

## 🛠️ Instalación y Desarrollo Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/iLuisAFG/SushiHari.git
   cd SushiHari
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
